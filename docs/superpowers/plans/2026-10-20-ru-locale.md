# План 5 — полная русская локализация (спецификация, раздел 4.5)

**Цель:** весь интерфейс ChatbotX доступен на русском языке; русскоязычный браузер получает его автоматически, язык можно переключить вручную; push-уведомления и страницы для клиентов (webview, бронирование) тоже на русском, если у пространства выбран русский.

**Архитектура:** русский добавляется как 22-я локаль next-intl (`ru`). Файл `messages/ru.json` создаётся сразу полной копией английского (иначе `i18n:check` и тесты каталога падают), затем переводится пакетами по разделам с помощью небольшого скрипта, который выдаёт «ещё не переведённые» строки и аккуратно вливает перевод с проверкой плейсхолдеров. В конце включается тест, запрещающий непереведённые строки (кроме явного списка: названия брендов и т. п.).

**Стек:** next-intl, ICU MessageFormat, vitest, tsx, Biome (ultracite).

## Найденные расхождения со спецификацией 4.5

1. Спецификация обещает автоопределение по `Accept-Language`, но в коде язык берётся только из cookie `NEXT_LOCALE`, по умолчанию `en`. **Исправляем** (задача 1): без cookie — язык браузера, если он поддерживается; иначе `en`.
2. Тест ICU требует, чтобы у перевода были ровно те же категории множественного числа, что у английского (`one/other`). Русскому нужны `one/few/many/other`. **Исправляем** (задача 1): для «строгих» локалей (`ru`) требуются все категории CLDR; остальные 21 локаль проверяются как раньше.
3. Термин «Рабочее пространство» из спецификации длинный для меню и кнопок — в глоссарии принимаем «Пространство».

## Глобальные ограничения

- Ничего не трогать в Geka, n8n, старом Dashboard, tmtr-runner, их БД и контейнерах.
- Каналы MAX/ZZAP/DROM не включать.
- Миграций БД в этом плане нет.

- Переводчики-помощники: не больше двух одновременно, рабочие файлы в `/var/tmp/ru` (переживает перезагрузку).

```ts
const parseAcceptLanguage = (header: string) =>
  header
    .split(",")
    .map((part) => {
      const [tag = "", ...params] = part.trim().split(";")
      const qualityParam = params.find((param) => param.trim().startsWith("q="))
      const quality = qualityParam ? Number(qualityParam.trim().slice(2)) : 1
      return { tag: tag.trim(), quality: Number.isNaN(quality) ? 0 : quality }
    })
    .filter(({ tag, quality }) => tag !== "" && tag !== "*" && quality > 0)
    .sort((left, right) => right.quality - left.quality)

const isEnglishTag = (tag: string) => tag.toLowerCase().split("-")[0] === "en"

export const pickAcceptLanguageLocale = (
  header: string | null | undefined,
): Locale | undefined => {
  if (!header) {
    return
  }
  for (const { tag } of parseAcceptLanguage(header)) {
    const locale = resolveLocale(tag)
    if (locale !== defaultLocale || isEnglishTag(tag)) {
      return locale
    }
  }
}
```

- [x] **2.2 `apps/builder/scripts/i18n/catalog.ts`:**

```ts
export type Catalog = { [key: string]: string | Catalog }
export type FlatCatalog = Record<string, string>

const joinPath = (prefix: string, key: string) =>
  prefix ? `${prefix}.${key}` : key

export const flattenCatalog = (catalog: Catalog, prefix = ""): FlatCatalog => {
  const result: FlatCatalog = {}
  for (const [key, value] of Object.entries(catalog)) {
    const path = joinPath(prefix, key)
    if (typeof value === "string") {
      result[path] = value
      continue
    }
    Object.assign(result, flattenCatalog(value, path))
  }
  return result
}

export const buildCatalogLike = (
  shape: Catalog,
  flat: FlatCatalog,
  prefix = "",
): Catalog => {
  const result: Catalog = {}
  for (const [key, value] of Object.entries(shape)) {
    const path = joinPath(prefix, key)
    if (typeof value === "string") {
      if (flat[path] !== undefined) {
        result[key] = flat[path]
      }
      continue
    }
    const child = buildCatalogLike(value, flat, path)
    if (Object.keys(child).length > 0) {
      result[key] = child
    }
  }
  return result
}

const simplePlaceholderPattern = /\{[A-Za-z][\w.-]*\}/g
const icuArgumentPattern = /\{[A-Za-z][\w.-]*,\s*(plural|select|selectordinal)\s*,/

const simplePlaceholders = (value: string) =>
  [...(value.match(simplePlaceholderPattern) ?? [])].sort().join()

export const listPendingKeys = (props: {
  english: FlatCatalog
  target: FlatCatalog
  sameAsEnglish: ReadonlySet<string>
  sections: readonly string[]
}) =>
  Object.keys(props.english).filter((key) => {
    const section = key.split(".")[0] ?? ""
    return (
      props.sections.includes(section) &&
      props.target[key] === props.english[key] &&
      !props.sameAsEnglish.has(key)
    )
  })

export type MergeResult = {
  target: FlatCatalog
  sameAsEnglish: string[]
  errors: string[]
}

export const mergeTranslations = (props: {
  english: FlatCatalog
  target: FlatCatalog
  sameAsEnglish: readonly string[]
  translations: FlatCatalog
}): MergeResult => {
  const errors: string[] = []
  const target = { ...props.target }
  const sameAsEnglish = new Set(props.sameAsEnglish)
  for (const [key, value] of Object.entries(props.translations)) {
    const englishValue = props.english[key]
    if (englishValue === undefined) {
      errors.push(`${key}: key does not exist in en.json`)
      continue
    }
    if (typeof value !== "string" || value.trim() === "") {
      errors.push(`${key}: empty translation`)
      continue
    }
    const isIcu = icuArgumentPattern.test(englishValue)
    if (!isIcu && simplePlaceholders(value) !== simplePlaceholders(englishValue)) {
      errors.push(`${key}: placeholders differ from English`)
      continue
    }
    target[key] = value
    if (value === englishValue) {
      sameAsEnglish.add(key)
    } else {
      sameAsEnglish.delete(key)
    }
  }
  return { target, sameAsEnglish: [...sameAsEnglish].sort(), errors }
}
```
