# Русская локализация — глоссарий и правила стиля

Каталог: `apps/builder/messages/ru.json`. Перевод ведётся пакетами через `pnpm --filter builder i18n:ru` (`pending` / `merge` / `status`), см. `docs/superpowers/plans/2026-10-20-ru-locale.md`.

## Стиль

- Обращение на «вы» со строчной буквы.
- Кнопки и пункты меню — глагол в инфинитиве: «Сохранить», «Подключить», «Удалить».
- Заголовки и подписи — с заглавной только первое слово (не Title Case).
- Кавычки «ёлочки»; букву «ё» не используем.
- Коротко и без канцелярита: «Не удалось сохранить», а не «Произошла ошибка при сохранении».
- Сообщения об успехе — в прошедшем времени: «Сохранено», «Канал подключен».
- Если пол человека неизвестен — безличные формы: «Отправлено вложение», а не «Отправил вложение».

## Что не переводим

- Названия брендов, каналов и сервисов: MAX, ZZAP, DROM, Telegram, WhatsApp, Messenger, Instagram, Threads, TikTok, Zalo, Google, Meta, OpenAI, Gemini, Claude и т. п.
- Плейсхолдеры `{name}`, URL, коды, идентификаторы, имена переменных.
- HTML/rich-text теги внутри строки (`<b>…</b>`, `<link>…</link>`) — сами теги сохраняем, переводим текст внутри.

Если правильный перевод совпадает с английским (бренд, код), оставляем английское значение — скрипт занесёт ключ в `apps/builder/__tests__/fixtures/ru-same-as-english.json`.

## Множественное число

В русском четыре категории: `one` (1, 21), `few` (2–4, 22), `many` (5–20, 25), `other` (дроби). Все четыре обязательны; `=0`/`=1` из английского сохраняются.

```
{count, plural, =0 {Нет контактов} one {# контакт} few {# контакта} many {# контактов} other {# контакта}}
```
