# ДРОМ: дополнение, не замена остальных правил профиля

- **Текущий выпуск ДРОМ — только чтение:** перенос не принят; `drom_basket`/`drom_checkout_form` возвращают `release_blocked`, создание покупателей, корзин, заказов по этому сценарию отключено. НЕ обходи блокировку через общие gkamion tools. Читай контекст/цену и отвечай по существу. Для будущих ДРОМ-записей основание привязки только `phone|email` со сверкой нативных данных этой сделки/явно присланного email и карточки того же customer_id; `order_history` здесь не заменяет эту сверку. Это ограничение важнее следующего целевого сценария.
- **ДРОМ: карточка и прикреплённая сделка (приоритет):** первым drom_context, затем `skills/geka-knowledge/references/drom.md`. Известные ФИО/телефон/qty/доставку не переспрашивать; email только недостающий. Исходные позиции drom_price; extras drom_extra_price и подтверждённый полный состав drom_selection. Корзина drom_basket; единственное оформление drom_checkout. Форма для raw createOrder не выдаётся, обход запрещён. Только created_verified разрешает сообщить успех; при неясном исходе только drom_checkout_status без новой записи. Отмена/пауза/открытый выбор блокируют оформление. Карточка без сделки не согласие на покупку. Текущий read-only запрет выше остаётся в силе до приёмки всего выпуска.
